# STAT 8561 report starter

This is the course's adaptation of The American Statistician's article structure, using ordinary Quarto. It is not an official journal submission template. See https://chikuang.github.io/teaching/2026F_stat8561/Project-Report.html#journal-style for the references, report requirements, and rubric.

1. Extract this ZIP into its own project folder.
2. Open `Project_Report.qmd` in RStudio or a text editor. Keep the required output filename Project_Report.pdf.
3. Replace the title, authors, abstract, and every writing prompt with your own work. The prompts are guidance, not text for submission.
4. Add executable R chunks to generate the results. Keep code needed for reproducibility in the source/supporting files; show only selected results in the main text. If you add a .bib file, declare it in the YAML and submit it too.
5. Run `quarto render Project_Report.qmd --to pdf` (using the renamed file for STAT 8670). A working Quarto/LaTeX installation is needed for PDF rendering. `--to html` is useful for preview; submit the PDF and matching source.
6. Write 8-10 pages of main text, including the abstract, excluding a separate title page, references, and appendices. Maintain readable 11- or 12-point text and standard margins.

The original course requirements still apply. See the project report page for grouping, due date, reproducibility, filenames, and submission details.
